# 01. 경유 매장: 지도-리스트 동기화 실험

![경유 매장 화면](../image1.png)

## 문제 인식
경유 매장 화면에서 지도와 리스트가 동시에 보이지만, 현재는 연동이 약합니다.

- 지도를 이동해도 리스트 변화가 없음
- 리스트를 정렬해도 지도 변화가 없음

이로 인해 사용자가 매장 탐색을 반복할 가능성이 있습니다.

## 가설
출발지/중간 지점/목적지 선택을 먼저 제공하고 지도-리스트를 동기화하면,
매장 선택까지 걸리는 시간이 줄어들 수 있습니다.

## A/B 설계
- A안: 기존 화면(비연동)
- B안: 지점 선택 탭 + 지도↔리스트 동기화

## 지표
### Primary
- Time-to-Select
- 정의: 목적지 입력 완료 시점 ~ 최종 매장 선택 시점의 시간차

### Guardrail
- 구매 지연 시간
- 정의: 매장 선택 시점 ~ 결제 완료 시점의 시간차

## 판단 기준
- Ship: Time-to-Select 개선 + 구매 지연 악화 없음
- Hold: Time-to-Select 개선은 있으나 구매 지연 악화
- Kill: 개선이 확인되지 않음
